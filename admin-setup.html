উপরের “সংযোগ” তালিকায় GitHub টোকেনের মেয়াদ নিজে থেকে যাচাই হয়; ১৪ দিন বাকি থাকলে হলুদ (!), মেয়াদ শেষ হলে লাল (×) দেখাবে। প্রোডাক্ট ম্যানেজারেও তখন সতর্কতা আসবে। কোনো টোকেন চ্যাট, ই-মেইল বা কোডে পেস্ট করবেন না।

GitHub টোকেন বদলানোর ধাপ (মেয়াদ শেষ হলে বা ভুলে মুছে গেলে)
  1. github.com → ছবিতে ক্লিক → Settings → নিচে Developer settings → Personal access tokens → Fine-grained tokens।
  2. পুরোনো টোকেন থাকলে নামের ওপর ক্লিক করে Regenerate token চাপুন (একই নাম ও পারমিশন থাকে), নইলে Generate new token।
  3. নতুন হলে: Resource owner muslim-abaya-landingpage; Repository access → Only select repositories → Luxury-Dress-BD; Permissions → Add permissions → Contents → Read and write।
  4. টোকেন (github_pat_…) একবারই দেখায় — সাথে সাথে কপি করুন।
  5. Cloudflare → Workers & Pages → luxury-dress-bd → Settings → Variables and Secrets → GITHUB_TOKEN-এর পাশে Edit → নতুন টোকেন পেস্ট → Save। (Apps Script-এর টোকেন হলে: Apps Script → Project Settings → Script Properties → GITHUB_TOKEN → Edit।)
  6. Cloudflare-এ বদলালে নতুন টোকেন পরের ডিপ্লয় থেকে কাজ করে — যেকোনো একটা প্রোডাক্ট সেভ করলেই ডিপ্লয় হয়। তারপর এই পেজে “আবার যাচাই” চাপুন; সবুজ ✓ দেখালে কাজ শেষ।
