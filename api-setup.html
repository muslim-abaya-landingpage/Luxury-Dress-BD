API সেটআপ ও যাচাই

Checkout, sign up এবং newsletter-এর Apps Script Web App সংযোগ যাচাই করুন। এই পরীক্ষা শুধু read-only OrderSchema GET request পাঠায়; কোনো order, customer বা subscriber row তৈরি বা পরিবর্তন করে না।

এই পেজ কোনো secret বা password সংরক্ষণ করে না। Subscribe GET probe এখানে চালানো হয় না।

OrderSchema ফল কীভাবে বুঝবেন

  1. সফল হলে ok: true, schema version এবং কলাম mapping দেখা যাবে।
  2. সাইজ, মোট টাকা, Order ID ও status-এর কলাম যথাক্রমে H, I, J ও K হওয়া উচিত।
  3. API পুরোনো version-এর response দিলে Apps Script-এ source Save করে বিদ্যমান deployment-এ New version প্রকাশ করুন।

নিরাপদ update নির্দেশনা

  1. Apps Script source copy page-এ canonical project-এর সব source file দেখুন।
  2. শুধু মূল Code.gs-এর doGet router ব্যবহার করুন; আলাদা Fix-doGet file যোগ করবেন না।
  3. Apps Script-এ code Save করার পর Deploy → Manage deployments → Edit → Version: New version → Deploy নির্বাচন করুন।
  4. বিদ্যমান deployment edit করলে `/exec` URL একই থাকে; নতুন deployment বানালে সাইটের URL-ও আলাদাভাবে update করতে হবে।
