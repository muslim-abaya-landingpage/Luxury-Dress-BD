পাসওয়ার্ড রিসেট

আপনার Admin account-এ যুক্ত ইমেইল দিন। মিল থাকলে সেই ঠিকানায় ১০ মিনিটের জন্য কার্যকর একটি একবার-ব্যবহারযোগ্য reset link পাঠানো হবে।

নিরাপত্তার কারণে account আছে কি না এই পেজ তা নিশ্চিত করে না। কোনো ইমেইল না এলে Spam/Junk দেখুন অথবা মূল অ্যাডমিনের Google Sheet-এর Muslim Abaya → Admin password reset অপশন ব্যবহার করুন।

নতুন পাসওয়ার্ড দিন

এই নিরাপদ reset link একবারই ব্যবহার করা যাবে। নতুন password কমপক্ষে ১২ অক্ষরের রাখুন।
