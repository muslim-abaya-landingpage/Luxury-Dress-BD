বিজ্ঞাপনের অডিয়েন্স

—

আপনার নিজের অর্ডার থেকে বানানো কাস্টমার তালিকা। এক ক্লিকে CSV ডাউনলোড করে Meta (Facebook) বিজ্ঞাপনে আপলোড করতে পারবেন। ফাইলে শুধু ফোন নম্বর, নাম আর দেশ থাকে — ঠিকানা থাকে না।

১. আসল ক্রেতা

…

যারা অন্তত একবার পণ্য হাতে পেয়েছেন (ডেলিভারি সম্পন্ন)। প্রত্যেকের মোট কেনাকাটার টাকাও ফাইলে থাকে।

কখন ব্যবহার করবেন: নতুন কাস্টমার খুঁজতে — এই তালিকা দিয়ে Lookalike বানান। Meta এদের মতো নতুন মানুষকে বিজ্ঞাপন দেখাবে।

২. বারবার কেনা কাস্টমার

…

যারা ২ বা তার বেশিবার ডেলিভারি নিয়েছেন — আপনার সবচেয়ে বিশ্বস্ত কাস্টমার।

কখন ব্যবহার করবেন: নতুন কালেকশন বা অফার এলে সরাসরি এদের দেখান। খরচ কম, অর্ডার বেশি আসে।

৩. সব কাস্টমার

…

যারা কখনো অর্ডার করেছেন (Fake ও সমস্যাজনক নম্বর বাদে)।

কখন ব্যবহার করবেন: ঈদ/সেল-এর মতো বড় অফারে সবাইকে মনে করিয়ে দিতে।

৪. চেকআউট শুরু করে থেমে গেছে

…

যারা চেকআউটে নম্বর দিয়েছিলেন কিন্তু পরে আর অর্ডার করেননি।

কখন ব্যবহার করবেন: "আপনার পছন্দের পণ্যটি এখনো আছে" ধরনের বিজ্ঞাপনে — কেনার খুব কাছে ছিলেন।

৫. বাদ দেওয়ার তালিকা

…

Fake অর্ডার করা নম্বর, ব্লক করা নম্বর, আর যারা ২+ বার বাতিল/ফেরত দিয়েছেন কিন্তু কখনো নেননি। (Fake নম্বর সময়সীমা যা-ই হোক বাদ যায়।)

কখন ব্যবহার করবেন: প্রতিটি বিজ্ঞাপনে Exclude হিসেবে দিন — এদের পেছনে বিজ্ঞাপনের টাকা নষ্ট হবে না।

Meta-তে নিজে থেকে হালনাগাদ (প্রতি শনিবার)

চালু করলে উপরের ৫টি তালিকা (গত ৬ মাস) প্রতি সপ্তাহে নিজে থেকে আপনার Ad account-এর অডিয়েন্সে বসে যাবে — "MA auto · …" নামে। ফাইল ডাউনলোড/আপলোড লাগবে না। Meta-তে শুধু ফোন, নামের প্রথম অংশ ও দেশের এনক্রিপ্ট করা (hash) রূপ যায়।

লোড হচ্ছে…

চালু করতে একবার যা করতে হবে (Meta Business Settings-এ):

  1. Business Settings → Users → System Users → আপনার যে System User দিয়ে Messenger চালু আছে সেটি খুলুন।
  2. Assign assets → Ad accounts → যে Ad account-এ বিজ্ঞাপন দেন সেটি বেছে Manage campaigns অনুমতি দিন।
  3. Generate new token → মেয়াদ Never → অনুমতিতে আগের সবগুলোর সাথে ads_management টিক দিন।
  4. নতুন Token অ্যাডমিন Setup → Messenger → "সব Page একসাথে" ঘরে বসিয়ে সেভ করুন। তারপর এই পেজ রিফ্রেশ করুন।

Meta-তে কীভাবে ব্যবহার করবেন (একবার শিখলেই হবে)

  1. উপরে তালিকা বেছে CSV ডাউনলোড করুন।
  2. Meta Ads Manager → Audiences খুলুন → Create audience → Custom audience → Customer list।
  3. ডাউনলোড করা ফাইলটি আপলোড করুন। কলামগুলো Meta নিজেই চিনে নেবে (phone, fn, ln, country)। "আসল ক্রেতা" ফাইলে value কলামও আছে — Meta জিজ্ঞেস করলে "হ্যাঁ, customer value আছে" বেছে নিন।
  4. অডিয়েন্সের নাম দিন, যেমন: MA – আসল ক্রেতা – নভেম্বর ২০২৬। Meta মেলাতে কয়েক ঘণ্টা সময় নিতে পারে।
  5. Lookalike: Audiences-এ "আসল ক্রেতা" অডিয়েন্সে টিক দিন → Create Lookalike → দেশ Bangladesh → ১%। নতুন কাস্টমারের বিজ্ঞাপনে এটাই দিন।
  6. বাদ দেওয়া: বিজ্ঞাপন বানানোর সময় Audience অংশে Exclude-এ "বাদ দেওয়ার তালিকা" দিন।
  7. মাসে একবার নতুন করে ডাউনলোড করে একই অডিয়েন্সে আপলোড করুন (Audience → Edit → Add customers), যাতে তালিকা হালনাগাদ থাকে।

ওয়েবসাইট ভিজিটরদের তালিকা: কারা সাইটে এসে প্রোডাক্ট দেখেছে বা কার্টে রেখেছে — এই ডেটা Meta পিক্সেলে থাকে, Meta তা ডাউনলোড করতে দেয় না। সেটা Ads Manager-এই বানাতে হয়: Custom audience → Website → পিক্সেল বেছে যেমন "ViewContent, গত ৩০ দিন"।

এই ফাইলে কাস্টমারের ব্যক্তিগত তথ্য আছে — শুধু Meta-তে আপলোডের জন্য ব্যবহার করুন, অন্য কাউকে দেবেন না, কাজ শেষে কম্পিউটার থেকে মুছে দিন। প্রতিটি ডাউনলোড কার্যকলাপ লগে জমা থাকে।
