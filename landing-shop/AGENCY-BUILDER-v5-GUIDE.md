# Webzo BD Agency Builder v5

## নতুন workflow
1. `admin.html` খুলুন।
2. **+ New Client** → Business name → Template → Phone → **Create Project**।
3. Theme, brand, products, gallery, delivery, tracking edit করুন।
4. **Save Project** চাপুন। Project browser localStorage-এ থাকবে।
5. **Projects** থেকে Open / Clone / Delete করা যাবে।
6. Client handover-এর জন্য `Export Project` JSON backup এবং `Download config.js` ব্যবহার করুন।

## Templates
- Fashion / Abaya
- Cosmetics / Beauty
- Gadget / Electronics
- Food / Restaurant
- General Business

Template একটি starting configuration; পরে সব field বদলানো যাবে।

## গুরুত্বপূর্ণ
এই v5 static/offline agency builder। Project data এই browser/device-এর localStorage-এ থাকে। Browser data clear করলে project হারাতে পারে, তাই প্রতিটি client-এর **Export Project** JSON backup রাখুন। Cloud login, multi-device sync, secure order dashboard ও database পরের backend phase-এর কাজ।
