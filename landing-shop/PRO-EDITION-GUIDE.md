# Webzo BD Landing Page Builder — PRO Edition

## New in PRO
- Premium Glass 3D gallery with side previews
- Fullscreen product lightbox
- Double-click / double-tap zoom
- Swipe and keyboard navigation in fullscreen viewer
- Admin toggles for lightbox, zoom, autoplay and side previews
- Import / Export Client Project JSON for reusable agency workflow
- Existing central theme, COD order flow, stock, delivery, tracking and responsive system retained

## Agency workflow
1. Open `admin.html`.
2. Import an existing client project or configure a new client.
3. Set brand/theme, gallery, products, delivery and tracking.
4. Preview at mobile/tablet/desktop widths.
5. Export Project JSON for your private archive.
6. Download `config.js` and replace the site config before deployment.
7. Do not deploy admin files for clients unless you intentionally want the builder public.

## Security note
This remains a static builder. It is not an authenticated SaaS admin panel. Keep client project JSON and admin tools private.
