Product Link Manager

Manage product links for Quick Access Pages — e.g., Abaya categories, Two-piece sets, etc.

Go to Product Manager →
Instructions:
  1. Select the Page Type — e.g., Category Page (Default = abaya.html)
  2. Edit links in the product-links-data.js file.
  3. Refresh the product catalog page using Ctrl+F5 to see changes.

Note: Make sure the page name matches your URL structure exactly.

Data format: JSON for Category/Sub-category · Link/ID: category-products.js
