# Security Policy

Thank you for helping keep **Muslim Abaya** secure.

The security and privacy of our customers are important to us. If you discover a security vulnerability in this project or on our website, please report it responsibly so we can investigate and resolve it as quickly as possible.

## Supported Versions

| Version | Supported |
| -------- | --------- |
| Latest | ✅ |
| Older Versions | ❌ |

Only the latest version of this project receives security updates.

## Reporting a Vulnerability

Please **do not create a public GitHub issue** for security vulnerabilities.

Instead, report the issue privately using the following contact:

**Organization:** Muslim Abaya  
**Website:** <https://muslimabaya.com>  
**Security Email:** muslimabeya@gmail.com

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the vulnerability
- The affected page or feature
- Screenshots or proof of concept (if available)
- Any suggested fix (optional)

## Response Timeline

We aim to:

- Acknowledge your report within **48 hours**
- Investigate the issue as quickly as possible
- Keep you informed throughout the investigation
- Release a security fix as soon as it is verified
- Notify you when the issue has been resolved
  
## Responsible Disclosure

Please do not publicly disclose any security vulnerability until we have had a reasonable opportunity to investigate and resolve the issue.

We sincerely appreciate the efforts of security researchers and members of the community who help keep **Muslim Abaya** safe for everyone.

Thank you for helping us improve the security of our project.
