Select a Category from the left to add products — they will automatically be added to that page + Home. Just input image, price, size, and color.

Bulk Images →

  1. Select ① Abaya to add products → abaya page + Home
  2. Select ④ Two-Piece to add products → premium-two-piece page + Home
  3. Select ⑤ Embroidery to add products → embroidery page + Home (Set enabled: true in menu if required)
  4. For each product: Image, Price, Size, Color → Save → Replace File → Netlify
