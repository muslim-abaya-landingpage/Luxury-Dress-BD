এই page-এ canonical project-এর সব source file আছে: Code.gs, AdminOrders.gs, FixSheetHeaders.gs, BoostAutoDate.gs, CatalogPublish.gs, CourierIntegrationAudit.gs, DataFixes.gs, Fix-doGet.gs, InstallDateTrigger.gs, LiveStock.gs, Monitor.gs, Operations.gs, OrderSync.gs, ProductPicker.html, SizeCore.gs

গুরুত্বপূর্ণ: Admin dashboard-এর সব API চালাতে নিচের সব ফাইল একই Apps Script project-এ রাখতে হবে। .gs ফাইলের জন্য ＋ → Script, আর .html ফাইলের জন্য ＋ → HTML ব্যবহার করুন; একই নাম রেখে প্রতিটি কোড সংশ্লিষ্ট ফাইলে কপি করুন। একাধিক doGet function রাখবেন না—canonical router শুধু Code.gs-এ।

  1. প্রতিটি source file-এর নাম অনুযায়ী Apps Script file তৈরি বা update করুন।
  2. Save চাপুন এবং npm run test:backend parity test পাস হয়েছে কি নিশ্চিত করুন।
  3. Deploy → Manage deployments → Edit → Version: New version → Deploy করে বিদ্যমান Web App URL রাখুন।
