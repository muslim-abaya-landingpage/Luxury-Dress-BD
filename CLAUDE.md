# Rules for anyone (people or AI assistants) changing this repository

- The owner uses another modest-wear shop's website as a **design reference only**. That shop's name must
  **never** appear anywhere in this repository: not in code, comments, tests, file names, page text,
  commit messages, branch names or pull requests. Its name is the word spelled by the character codes
  97 110 122 97 97 114. Write "the reference store" or "Muslim Abaya style" instead.
- `tests/backend/no-reference-brand-name.test.cjs` fails if the name is in a tracked file, and the
  `brand-name-guard` workflow fails if a pushed commit message contains it.
- Reply to the owner in Bangla. Only free tools and services.
